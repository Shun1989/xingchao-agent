# UI 收尾验收（2026-09-21）

沿用已确认的航海主题、任务优先与轻量动效方向。本轮使用真实 Electron AppShell，而不是仅渲染独立路由。

## 已处理

1. 紧凑舰长常驻工具栏和气泡遮挡任务说明、技能筛选器：改为标题栏头像与控制入口，保留 Windows 窗口按钮空间。语音设置按需展开，支持入口及面板内 Escape、外部点击关闭，Escape 返回入口焦点。
2. 展开设置面板透出底层文字：使用不透明底层，保留舰队表面配色。音量、语速有可见标签。
3. 基础浅色模式与深色舰队搭配时搜索框出现白底浅字：搜索框跟随舰队输入表面，键盘焦点使用明确描边。
4. 侧栏空状态统一使用星潮航局名称。

## 可复现验收

先构建应用，再运行 `node --experimental-strip-types scripts/ui-shell-smoke.ts`。

脚本创建独立临时 profile，验证 userData 隔离并在退出时清理；不配置模型、不发送模型请求。截图输出到 `.wanta-dev/ui-shell/after/`。

覆盖 1440×900 与 1024×640 窗口：聊天空态、舰队港口、航海图、舰长面板、设置、添加模型弹窗、连接空态、本机技能列表。验证面板与模型弹窗 Escape、焦点返回、主导航状态，并要求没有 renderer pageerror。浅色基础模式下继续验证舰队主题搜索框。

本轮全量测试：3027 通过，20 跳过，0 失败；最终键盘与外部点击补充断言后，CaptainHost 的 11 项测试通过。类型检查、lint 和生产构建通过。独立代码复核未发现剩余 Critical / Important。
