# 研究基线与来源

## 固定基线

- 上游桌面 Agent 基线：`oomol-lab/wanta` commit `470bbe1c0b48322e11d5955f9023362117776f09`，Apache-2.0。
- Alice 公开内容：`itshen/Alice_methodology` 仅作为 MIT 方法论参考；没有把它描述或使用为 Alice 产品源码。
- WorkBuddy：仅借鉴“专业专家、日常助理、多 Agent 协作”和真实产物交付的公开产品思路。

## 采用的工程原则

- UI、Agent 运行时、角色内容与主题系统相互解耦。
- 人格只影响表达、取舍和协作方式，不替代专业能力、工具权限或事实验证。
- 一个主团对结果负责，最多两个支援团提供有边界的子成果。
- 本地文件、密钥、权限和执行日志沿用 Wanta 已验证的主进程安全边界。
- 公开包只包含原创航海世界观；平台仅提供私人内容包导入规范。
