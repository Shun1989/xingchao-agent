# Xingchao Navigation 0.1.0-beta.1 — unsigned Windows public beta

Unsigned Windows x64 public test build. Read the test boundaries below before trying it.
This prerelease is not a signed stable release or a claim of complete production acceptance.

## Scope

An early Windows x64 beta of the nautical-themed desktop Agent workspace. This is not a signed
stable release. It is intended for testers who can report problems and retain backups of their work.
Users supply their own model-provider configuration; no provider credits or API keys are included.

The candidate includes Mission retry-history preservation, repair of failed dispatch-result writes
without re-executing an Agent, and Mission ledger export and corrupt-ledger recovery.
Electron communication now uses first-party typed IPC with explicit service method allowlists;
the two former connection dependencies are no longer included in this rebuilt candidate.

## Download and verification

Use only the installer attached to this repository's matching GitHub prerelease. Check its SHA-256
against the attached `SHA256SUMS.txt`, for example with PowerShell:

```powershell
Get-FileHash -LiteralPath '<downloaded-installer-path>' -Algorithm SHA256
```

The installer and application executable are intentionally **not Authenticode-signed**. The checksum
checks file consistency; it does not authenticate a publisher or substitute for a trusted signature.
Windows or a browser may show an unknown-publisher or SmartScreen warning. Smart App Control and
managed-device policies may prevent installation or execution. Do not disable system protection or
install an untrusted root certificate to run this beta. If the app is blocked, report the Windows
version and exact message and wait for a compatible distribution.

## Test boundaries and known limitations

- This first beta must not be described as production-ready or as having passed all real-provider
  workflows. Deterministic tests and the packaged onboarding/restart probe do not prove paid model
  execution, deliverable quality or every permission/cancellation path.
- An in-place upgrade from a previous public version cannot be exercised before a previous public
  version exists. Automated live updater acceptance remains separate from metadata validation.
- Clean-system installer/uninstaller acceptance and the complete transitive notice inventory remain
  unfinished. The packaged application's isolated onboarding/restart checks passed; these do not
  replace installer lifecycle tests. Identified license notices are included with this build.
- The signed stable workflow remains separate. Stable clients must not receive this prerelease as a
  stable update; a fresh beta installation defaults to the beta channel.
- Back up valuable project files. Mission ledger export preserves Mission records, not the complete
  conversation database, credentials or deliverable files.
